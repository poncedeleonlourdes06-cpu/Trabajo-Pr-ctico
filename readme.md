Proyecto Práctico JavaScript

1. ¿Qué hace mi proyecto?

Mi proyecto es una página web creada con HTML, CSS y JavaScript. Permite interactuar con distintas funciones del navegador y mostrar información de manera dinámica.

2. ¿Qué funcionalidades implementé?

* Saludo personalizado con el nombre ingresado.
* Muestra el ancho y alto de la ventana.
* Indica si hay conexión a Internet.
* Permite obtener la ubicación del usuario.
* Recarga la página.
* Permite activar el modo oscuro.
* Muestra mensajes dinámicos.
* Al hacer clic en el título, cambia su color.
* Permite avanzar y retroceder en el historial de navegación.
3. ¿Qué conceptos de BOM utilicé?

Utilicé diferentes elementos del BOM, como:

* window.innerWidth y window.innerHeight para conocer el tamaño de la ventana.
* window.addEventListener() para detectar cambios.
* navigator.onLine para comprobar la conexión.
* navigator.geolocation para obtener la ubicación.
* location.reload() para recargar la página.
* history para avanzar y retroceder.

4. ¿Qué conceptos de DOM utilicé?

Utilicé el DOM para conectar JavaScript con los elementos de HTML. Entre ellos:

* document.getElementById().
* Modificación del contenido de la página.
* Eventos con addEventListener().
* Botones que ejecutan funciones.
* Cambios en los elementos mediante JavaScript.
5. ¿Qué funcionalidad extra agregué?

Agregué como extra que, al hacer clic en el título, este cambia de color.

6. ¿Qué fue lo que más me costó resolver?

Lo que más me costó fue implementar la función para obtener la ubicación del usuario. Me ayudé con los videos de la clase y repasando los temas vistos. También tuve algunas dificultades para volver a conectar el proyecto con el repositorio local de GitHub, pero pude resolverlo practicando y siguiendo los pasos indicados.
